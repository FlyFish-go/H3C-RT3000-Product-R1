# RT3000 Machine-B 救援与回切

完整排查步骤见 [第五部分：故障救援](05-RECOVERY.md)；安装与切换前请从 [教程总览](INSTALL.md) 开始阅读。

本项目在 RT3000 Machine-B 上实测了从运行中的 QSDK 主动切回原厂、再从原厂切回 QSDK。**QSDK 无法启动时是否自动回退原厂、写入时断电、以及 U-Boot + TFTP 完整 NAND 救援均未端到端验证。** 原厂系统分区 `mtd15` 保留，并不保证两个系统都无法启动时无需 TTL 就能恢复。请按第五部分的证据边界操作。

此流程不适用于尚未验证的 RT3000 其他样机或 RW3000、RC3000、NX30。
