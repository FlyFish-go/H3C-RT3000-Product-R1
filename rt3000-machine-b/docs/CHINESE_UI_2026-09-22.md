## 本次修改

- RT3000 目标默认包含 LuCI 和 `luci-i18n-base-zh-cn`、`luci-i18n-firewall-zh-cn`、`luci-i18n-opkg-zh-cn`。
- 加入 `config/luci-zh-cn.config` 中文叠加配置；历史 `candidate13.config` 保持不变。
- 首次初始化在翻译包注册完成后，将 LuCI 的自动语言设置改为 `zh_cn`。保留已经明确选择的语言，支持在界面中自行切换。
- 本镜像同时包含先前已确认的 2.4 GHz 调试默认配置：SSID `RT3000`、无密码、开启；5 GHz 默认关闭。

## 后续无 TTL 安装与升级工作的前提

当前 `platform_check_image()` 尚未接受 `h3c,rt3000`，`platform_do_upgrade()` 明确拒绝 RT3000 系统内升级，目标也未输出已经支持的 sysupgrade 安装包。本轮只加入中文，不移除这些保护。

后续需分别验证：原厂系统进入第二槽位的网络安装流程、运行系统中的双向切换与回退、保留配置的系统内升级及失败处理。通过后再把准确步骤写入面向新手的安装教程，不能仅补写文档就声称这些功能已经可用。
