本次以经过审计的工作区快照作为发布内容。公开导出不携带内部 Git 历史；已有 GitHub 仓库历史不重写，新提交沿用公开仓库父提交，使用 GitHub noreply 身份或连接器身份。

## 脱敏与保留

- 开发样机工厂 MAC 和派生地址替换为合成测试向量及对应的派生结果；生产 MAC 算法不变，仍读取设备自身工厂值。
- 个人主目录、工作站名、串口适配器序列号和实验网段已替换或去除。历史验收文档中的这些值是脱敏示例，不是可直接套用的运行配置。
- 设备控制工具的串口路径为显式占位符，需要使用者配置自己的受控实验环境；公开仓库不附带 SSH 凭据或跳板机私有执行脚本。
- 原始 OEM BDF 诊断输入、私人 bring-up/事故日志和离线分区取证工具不纳入公开导出。当前构建所需的型号级兼容 BDF、生成器、边界明确的功率表输入和来源校验保留；它们不替代每台设备自身 ART 校准数据。
- `.codex/`、本地 AGENTS、签名私钥、下载/构建目录、完整串口与 SSH 日志、原始抓包、通知凭据和固件镜像不纳入公开快照。
- 原有上游许可证、公开作者署名、源码协议常量、通用默认 LAN 地址与上游合成测试样例保留。硬件型号、补丁代码和公开镜像哈希不是秘密，不做破坏性替换。
- 原有自动固件发布工作流替换为只读权限的离线源码检查；不会因为上传源码就自动生成 Release 或覆盖 gh-pages。
