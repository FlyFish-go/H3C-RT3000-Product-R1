H3C-RT3000-Product-R1 软件源 / package feeds

固件的 /etc/opkg/distfeeds.conf 自动包含这些源，不需要手动添加。

The firmware lists these feeds in /etc/opkg/distfeeds.conf by itself.

内核模块 / kernel modules (h3c_magic_core)

目录以内核版本命名，只包含对应内核的模块。Each directory is named after a kernel package version and only holds modules built for that kernel.

  • r14 HW-A / HW-B / HW-D
  • r14 HW-C
  • r11 HW-A / HW-B / HW-D
  • r11 HW-C

插件 / extra packages (h3c_magic_extra, r14+)

OpenClash、PassWall（opkg install h3c-passwall）、Tailscale、AdGuard Home、Argon 主题设置。代理插件需要 U-Boot 的大分区。Proxy plugins need the U-Boot merged single-system layout.

  • extra/Packages

在线更新 / online update

  • update/update.json（签名 / signature: update.json.sig）
