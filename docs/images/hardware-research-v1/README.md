# Hardware Research v1.0 — P0 public images

These publication images are derived only from project-owned H3C Magic RT3000 A/B/C photographs.

## Editing / evidence policy

- No generative image editing, inpainting, object replacement, or synthetic reconstruction.
- Public derivatives use only conservative visibility/layout operations: exposure/brightness lift, mild contrast/sharpness, rotation/layout, resizing/compression, and privacy redaction.
- Device-unique QR/label areas visible in board-overview photos were conservatively redacted.
- Exported images do not preserve EXIF metadata.
- Original JPEG/ARW files remain the private P0 evidence source and are not published here.
- For the four Sony ARW full-board photographs, the public board overviews in this directory were rendered from the camera-embedded 1616×1080 JPEG preview in the ARW file in the current publication environment; they are not described as full RAW demosaicing/development.

External NX30 / RC3000 / RW3010 / community photographs are intentionally not mirrored into this repository. The research document cites the original author/post/link instead unless explicit redistribution permission or a compatible license is documented.
